# NumPy Data Explorer

A compact Python/Jupyter project demonstrating core NumPy operations and the performance advantage of vectorized array computation.

## Demonstrated Concepts

- Creating one-dimensional and two-dimensional arrays
- `arange` and random integer arrays
- Indexing and slicing
- Vectorized arithmetic
- Square-root operations
- Row-wise and column-wise aggregation
- Mean, median, minimum, maximum, and standard deviation
- Reshaping and broadcasting
- Saving/loading arrays
- Basic timing comparison between Python lists and NumPy arrays

## Learning Outcome

The notebook shows why NumPy is a foundation of Python data science: array operations are concise, expressive, and substantially faster than equivalent element-by-element Python loops for many numerical workloads.
